## Release summary

Tescam 1.0 is the first App Store release. It provides local TeslaCam and
Sentry Mode review, synchronized multi-camera playback, timeline range
selection, camera selection, telemetry-aware workflows, and native evidence
export on iPhone, iPad, and Mac.
